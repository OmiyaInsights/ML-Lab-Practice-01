# ML-Lab-Practice-01

Simple Linear Regression on the Iris DatasetAn introductory machine learning project demonstrating how to build, train, evaluate, and visualize a Simple Linear Regression model using Python and Scikit-Learn. This repository uses the classic Iris dataset to predict a flower's petal length based on its sepal length.   🚀 Project OverviewLinear regression is a foundational supervised learning algorithm used to model the relationship between a scalar dependent variable ($y$) and one or more explanatory independent variables ($X$).In this notebook, we explore:Data Loading & Exploration: Importing libraries and inspecting tabular data structure using Pandas and Seaborn.   Data Preprocessing: Splitting data into training and testing subsets using Scikit-Learn's train_test_split.   Model Training: Fitting a Ordinary Least Squares (OLS) linear regression model.   Prediction & Visualization: Generating predictions on unseen test data and plotting the regression line against actual data points using Matplotlib.   Model Evaluation: Quantifying error and accuracy using Mean Squared Error (MSE) and the R-squared ($R^2$) score.   🛠️ Tech Stack & LibrariesPython 3.xNumPy: For high-performance array and vector operations.   Pandas: For data handling, manipulation, and DataFrame structures.   Scikit-Learn: For machine learning algorithms, dataset splitting, and performance metrics.   Matplotlib & Seaborn: For data visualization and plotting regression lines.   📂 Repository StructurePlaintext├── Simple_Linear_Regression.ipynb   # Complete Jupyter Notebook with code and outputs
├── Iris.csv                         # Dataset file containing iris flower attributes
└── README.md                        # Project documentation
